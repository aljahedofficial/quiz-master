# quiz-master

Free AI-powered PDF Quiz Generator web app for Vercel.

## Environment variables

Set these in Vercel Project Settings:

- `GROQ_API_KEY` (required): Groq API key.
- `GROQ_MODEL` (optional): override model ID. Defaults to `openai/gpt-oss-120b`.

## Deploy

1. Install dependencies: `npm install`
2. Deploy to Vercel.
3. Upload a PDF in the web app and generate a quiz.
